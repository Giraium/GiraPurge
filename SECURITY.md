# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please report security issues **privately** through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for an undisclosed vulnerability.

A useful report includes a short description, the affected release, device and host-app context, reproduction steps, and the security impact. Redact personal data and never send account tokens or passwords.

Ordinary bugs and feature requests belong in the public [issue tracker](https://github.com/Giraium/GiraPurge/issues).

## Scope

The official GiraPurge repository, website, package and source code. Unofficial, modified or rebranded builds are outside the support scope of Giraium Studio.

## Responsible disclosure

Please allow reasonable time for validation and remediation before publishing technical details. Security fixes are published only through the official GiraPurge repository and installation source.
