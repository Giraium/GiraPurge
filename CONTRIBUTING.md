# Contributing to GiraPurge

GiraPurge is maintained and released by **Giraium Studio**. Suggestions, bug reports and feature ideas are welcome when they are clear, respectful, and focused on safety, reliability, accessibility or usability.

## Where to send what

| You have | Use |
| --- | --- |
| A reproducible bug | [Bug report](https://github.com/Giraium/GiraPurge/issues/new?template=bug_report.md) |
| An idea or improvement | [Feature request](https://github.com/Giraium/GiraPurge/issues/new?template=feature_request.md) |
| A security vulnerability | A private report, see [SECURITY.md](SECURITY.md) |

Please read the README and search existing issues first. Include the device, host-app version, plugin version, steps to reproduce, expected result and actual result. Never include account tokens, passwords, private message contents or personal identifiers, and redact screenshots and logs before sharing them.

## Pull requests and redistribution

The repository accepts discussion and feedback, but the proprietary terms in `LICENSE.md` remain in force. Do not submit a pull request that copies code from an unofficial build, changes the project identity, removes attribution, introduces account-token handling, bypasses host-app safeguards, or turns GiraPurge into a redistributed or rebranded package.

A suggestion or pull request does not guarantee inclusion in an official release. Only Giraium Studio can approve, package, name and publish official GiraPurge releases.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md) and the project's proprietary terms.
